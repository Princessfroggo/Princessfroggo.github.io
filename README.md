# Princessfroggo.github.io
Vitamin and Wellness Monitoring App_Project Outline
I. Project Description
The purpose of this project is to create an app that helps users monitor the vitamins and nutrients they consume each day. The app would use advanced technology and health-related data to track a user’s vitamin intake and identify areas where the user may not be meeting recommended nutritional levels. The goal is to help users become more aware of their daily nutrition and overall wellness.
The app would not replace a doctor or provide a medical diagnosis. Instead, it would provide users with information about possible nutritional gaps and encourage them to speak with a healthcare professional when needed.

II. Problem Addressing
One problem this app would address is the possibility of nutritional deficiencies going unnoticed. Some people may experience symptoms such as tiredness, difficulty concentrating, or changes in how they feel without realizing that nutrition could be one factor involved.
Another concern is misdiagnosis or health concerns going unaddressed because users may not have enough information about their daily nutritional habits. By tracking vitamin and nutrient intake over time, the app could provide users with additional information that they can discuss with their healthcare provider.

III. Platform
The app would primarily be developed for the Android platform. Android would allow users to access the application from their smartphones and enter information throughout the day.
In the future, the application could also include cloud support so users could securely store their information and access their account from multiple devices.

IV. Front-End and Back-End Support
A. Front-End
The front end would be the part of the application that users interact with. It would include:
1.	User login and account creation
2.	Daily vitamin and food intake entry
3.	Dashboard showing vitamin and nutrient information
4.	Notifications and reminders
5.	Charts showing daily or weekly nutritional intake
6.	Settings and user profile information
B. Back-End
The back end would manage and store the information entered into the application. It would include:
1.	User account information
2.	Database storage
3.	Daily vitamin and nutrient records
4.	Secure user authentication
5.	Processing of nutritional data
6.	Communication between the application and database
The back end could also support cloud storage so information could be securely saved and retrieved when the user signs into the application.

V. Functionality
The main functionality of the application would be to allow users to track their daily vitamin and nutrient intake.
Users would be able to:
1.	Create a personal account.
2.	Enter foods, vitamins, or supplements they consume.
3.	View estimated daily vitamin and nutrient totals.
4.	Compare their intake with recommended nutritional guidelines.
5.	Receive notifications when their recorded intake may be below recommended levels.
6.	View daily, weekly, and monthly trends.
7.	Set reminders for vitamins or supplements.
8.	Create reports that could be shared with a healthcare professional.
9.	Review previous entries to better understand patterns in their nutrition.
The application would clearly explain that its information is for educational and wellness purposes and should not be considered a medical diagnosis.

VI. Design and Wireframes
The application would use a simple design so users could easily understand and navigate the system.
A. Login Screen
The first screen would allow the user to:
•	Sign in
•	Create an account
•	Reset a forgotten password
B. Home Dashboard
The main dashboard would display:
•	Daily vitamin intake
•	Nutritional progress
•	Vitamins that may be below the user's selected goals
•	Reminders
•	Quick access to add food, vitamins, or supplements
C. Add Intake Screen
The user would be able to enter:
•	Food or supplement name
•	Serving amount
•	Vitamin information
•	Time consumed
•	Notes
D. Progress Screen
The progress screen would use charts or graphs to show:
•	Daily intake
•	Weekly intake
•	Monthly trends
•	Changes in nutritional habits over time
E. Notifications Screen
The notification section would display reminders about:
•	Recording daily intake
•	Taking scheduled vitamins or supplements
•	Reviewing nutritional progress
•	Following up with a healthcare professional when appropriate
